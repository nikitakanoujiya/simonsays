# 🎮 Simon Says Game

A fun and interactive **Simon Says memory game** built using HTML, CSS, and JavaScript. The game challenges players to remember and reproduce an increasing sequence of button patterns.

## 🚀 Features

* Interactive Simon Says gameplay
* Random sequence generation
* Increasing difficulty with each level
* User input validation
* Game-over detection
* Restart functionality
* Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript** – Game logic and interactions

## 🎯 How to Play

1. Click the **Start** button.
2. Watch the sequence shown by the game.
3. Click the buttons in the same order.
4. Each successful round adds another step to the sequence.
5. One incorrect click ends the game.
6. Restart and try to beat your previous score!
